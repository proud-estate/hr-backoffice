# ระบบ HR และเงินเดือน

ระบบบันทึกข้อมูลพนักงานหลายบริษัท วันหยุดประเพณี การลา ขาด สาย คำนวณเงินเดือน (รายเดือน และรับทุก 15 วัน) และพิมพ์สลิปเงินเดือน
ใช้ **GitHub Pages** เป็นที่วางหน้าเว็บ และ **Firebase** (ของ Google) เป็นฐานข้อมูลกับระบบล็อกอิน ใช้ฟรีทั้งคู่สำหรับบริษัทขนาดนี้
ระบบนี้แยกจากเว็บร้านซักและระบบอื่นทั้งหมด มีโปรเจกต์ Firebase ของตัวเอง

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ระบบหลัก: หน้าล็อกอิน · พนักงาน · วันหยุดและโควตา · บันทึกลา/ขาด/สาย · เงินเดือน · สลิป · บัญชีผู้ใช้ |
| `config.js` | ค่าเชื่อมต่อ Firebase (ต้องแก้ 1 ครั้ง ในขั้นตอนที่ 4) |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล (วางใน Firebase ในขั้นตอนที่ 3) |
| `README.md` | คู่มือนี้ |

> ถ้ายังไม่ได้ใส่ค่าใน `config.js` เว็บจะเปิดใน **โหมดทดลอง** ใช้งานได้ครบ แต่เก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น และไม่มีหน้าล็อกอิน เหมาะไว้ลองกดดูก่อน

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ประมาณ 20–30 นาที)

### 1. เอาไฟล์ขึ้น GitHub
1. เปิด https://github.com/proud-estate/hr-backoffice
2. กด **Add file** > **Upload files** แล้วลากไฟล์ทั้ง 4 ไฟล์ (`index.html`, `config.js`, `firestore.rules`, `README.md`) ลงไป กด **Commit changes**
   - ไฟล์ `index.html` ตัวใหม่จะแทนที่ไฟล์เดิมให้เอง

### 2. เปิดหน้าเว็บด้วย GitHub Pages
ทำไว้แล้ว เว็บอยู่ที่ `https://proud-estate.github.io/hr-backoffice/`
(ถ้าทำ repository ใหม่: **Settings** > **Pages** > Source **Deploy from a branch** · Branch **main** และ **/ (root)** > **Save**)

### 3. สร้าง Firebase (โปรเจกต์ใหม่ แยกจากร้านซัก)
1. ไปที่ https://console.firebase.google.com แล้วกด **Create a project** ตั้งชื่อ เช่น `hr-backoffice` (ปิด Google Analytics ได้)
   - **อย่าใช้โปรเจกต์ `quinn-laundry` ของร้านซัก** ให้สร้างโปรเจกต์ใหม่
2. **เปิดระบบล็อกอิน:** เมนูซ้าย **Build > Authentication** > **Get started** > เลือก **Email/Password** > เปิด **Enable** > **Save**
3. ในหน้า Authentication แท็บ **Settings > Authorized domains** กด **Add domain** ใส่ `proud-estate.github.io` (ไม่ต้องมี https:// และไม่ต้องมีชื่อ repository)
4. **สร้างฐานข้อมูล:** เมนูซ้าย **Build > Firestore Database** > **Create database** > เลือก location **asia-southeast1 (Singapore)** > เลือก **Start in production mode** > **Create**
5. **ใส่กฎความปลอดภัย:** ในหน้า Firestore แท็บ **Rules** ลบข้อความเดิมทั้งหมด แล้วคัดลอกทุกบรรทัดจากไฟล์ `firestore.rules` ไปวาง กด **Publish**

### 4. เชื่อมเว็บกับ Firebase
1. ใน Firebase กดรูปเฟือง (ข้าง Project Overview) > **Project settings**
2. เลื่อนลงไปที่ **Your apps** กดไอคอน **`</>`** (Web) ตั้งชื่อแอป เช่น `hr-web` > **Register app**
3. จะเห็นโค้ด `const firebaseConfig = { apiKey: "...", ... }` ให้คัดลอกค่าแต่ละบรรทัด
4. กลับไปที่ GitHub เปิดไฟล์ `config.js` กดรูปดินสอ แล้วแทนที่ข้อความ `ใส่ apiKey`, `ใส่ authDomain` ฯลฯ ด้วยค่าที่คัดลอกมา กด **Commit changes**
5. รอ 1–2 นาทีให้ GitHub Pages อัปเดต

### 5. สร้างบัญชีผู้ดูแลระบบ
1. เปิด `https://proud-estate.github.io/hr-backoffice/`
2. ครั้งแรกจะขึ้นหน้า **ตั้งค่าครั้งแรก** ใส่ชื่อ **อีเมลจริง** (แนะนำ เพื่อใช้รีเซ็ตรหัสผ่านได้) และรหัสผ่าน
3. กดสร้าง ระบบจะเข้าหน้าหลักให้ทันที หน้านี้จะไม่ขึ้นอีก

### 6. สร้างบัญชีให้ HR คนอื่น
แท็บ **ผู้ใช้และสำรองข้อมูล** > ใส่ชื่อ ชื่อผู้ใช้ (ภาษาอังกฤษ เช่น `nok`) หรืออีเมล รหัสผ่าน อย่างน้อย 8 ตัว เลือกสิทธิ์ แล้วกด **สร้างบัญชี HR**
แจ้งชื่อผู้ใช้และรหัสผ่านให้เจ้าตัว HR เปิดเว็บเดียวกันแล้วล็อกอินได้ทันที ไม่ต้องยืนยันอีเมล

## การใช้งาน

1. **เพิ่มบริษัท** กด **+ เพิ่มบริษัท** ด้านบน (มีหลายบริษัทได้)
2. **วันหยุดและโควตา** ติ๊กวันหยุดนักขัตฤกษ์ที่บริษัทหยุด (ระบบมีรายการวันหยุดของปีให้แล้ว) วันที่ติ๊กจะหักจากโควตาวันหยุดประเพณี 13 วัน วันที่เหลือพนักงานใช้ลาแทนวันนักขัตฤกษ์ที่บริษัทไม่ได้หยุด และตั้งโควตาลาป่วย (30 วัน) ลากิจ (3 วัน) ลาพักร้อน และอัตราประกันสังคม
3. **พนักงาน** กรอกข้อมูลแต่ละคน รวมถึงวันเริ่มงาน รอบจ่าย (รายเดือน / ทุก 15 วัน) และติ๊กว่าหักประกันสังคมหรือไม่
4. **บันทึกลา / ขาด / สาย** ติ๊กเลือกพนักงาน เลือกประเภท ใส่ช่วงวันที่ แล้วบันทึก ลาป่วยแนบใบรับรองแพทย์ (รูปหรือ PDF) ได้ ไฟล์เก็บในฐานข้อมูล เปิดดูได้เฉพาะบัญชี HR
5. **เงินเดือน** เลือกเดือนและงวด กรอกรายได้อื่น/OT ภาษี และหักค่าใช้จ่ายอื่นๆ
6. **สลิปเงินเดือน** ติ๊กเลือกพนักงาน แล้วกด **พิมพ์สลิป** (เลือก Save as PDF ได้)

ทุกอย่างบันทึกเข้าฐานข้อมูลอัตโนมัติ มุมขวาบนจะแสดง **ซิงก์แล้ว** เข้าจากเครื่องไหนก็เห็นข้อมูลชุดเดียวกัน และเห็นการแก้ไขของ HR คนอื่นทันที

## สิทธิ์ของแต่ละบัญชี

| | ผู้ดูแลระบบ | เจ้าหน้าที่ HR |
|---|---|---|
| เพิ่มบริษัท กรอกพนักงาน การลา เงินเดือน พิมพ์สลิป | ได้ | ได้ |
| ลบบริษัท / ล้างข้อมูล | ได้ | ไม่ได้ |
| สร้างและปิดบัญชี HR | ได้ | ไม่ได้ |

## ลืมรหัสผ่าน
- **บัญชีที่ใช้อีเมล:** หน้าล็อกอิน พิมพ์อีเมลในช่องชื่อผู้ใช้ แล้วกด **ลืมรหัสผ่าน** ระบบจะส่งลิงก์ไปที่อีเมล
- **บัญชีที่ใช้ชื่อผู้ใช้:** ให้ผู้ดูแลระบบกด **ปิดบัญชี** คนนั้น แล้วสร้างบัญชีใหม่ให้ (ใช้ชื่อผู้ใช้ใหม่)

## ความปลอดภัย
- เปิดยืนยันตัวตนสองขั้น (2FA) ของบัญชี GitHub และบัญชี Google ที่ใช้สร้าง Firebase
- ค่าใน `config.js` เปิดเผยได้ ไม่ใช่รหัสลับ ข้อมูลถูกป้องกันด้วยกฎใน `firestore.rules` คนที่ไม่มีบัญชีจะไม่เห็นข้อมูลใดๆ
- ใช้เครื่องร่วมกับคนอื่น ให้กด **ออกจากระบบ** ทุกครั้ง
- กด **ดาวน์โหลดไฟล์สำรอง** ทุกสิ้นเดือน และเก็บไฟล์ในที่ปลอดภัย

## ย้ายข้อมูลจากเวอร์ชันเก่า
ถ้าเคยกรอกข้อมูลในเวอร์ชันที่เก็บในเครื่อง: เปิดเว็บจากเครื่องเดิม ล็อกอินบัญชีใหม่ ไปแท็บ **ผู้ใช้และสำรองข้อมูล** > **นำเข้าข้อมูล** ใส่ชื่อผู้ใช้และรหัสผ่านของระบบเก่า แล้วกด **นำเข้า**
